# Music Playlist Analysis System - Lana Del Rey Edition

## Proje Amacı
Bu proje, Lana Del Rey'in "Ultraviolence" albümündeki seçili şarkıların verilerini (şarkı adı, sanatçı, süre ve dinlenme sayısı) kullanarak analizler yapan bir Python uygulamasıdır.

## Kullanılan Methodlar
- **get_total_duration(songs):** Albümdeki şarkıların toplam süresini hesaplar.
- **get_most_played_song(songs):** Dinlenme sayısı en yüksek olan "Ultraviolence" şarkısını bulur.
- **get_average_duration(songs):** Şarkıların ortalama süresini hesaplar.
- **print_playlist(songs):** Şarkı listesini teknik detaylarıyla birlikte ekrana yazdırır.
- **main():** Uygulamanın ana fonksiyonudur; veri setini tanımlar ve analizleri başlatır.

Projeyi çalıştırmak için terminale şu komutu yazabilirsiniz:
```bash
python main.py
